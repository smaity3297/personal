Stage 03

Rerank and prepare context

Initial retrieval may return several candidates. Reranking improves relevance before the context is sent to the LLM.

Candidate → reranker → context

Retrieved candidates → Relevance model → Top K → Prompt context

A reranker can be a cross-encoder or specialized relevance model. It does not have to be a small LLM.

Stage 04

Generate a grounded answer

The orchestration layer combines system instructions, retrieved context, and the user query before calling the LLM.

Prompt assembly

SYSTEM: You are a helpful customer service assistant. Answer using only the provided context. If the context is insufficient, say you do not know. CONTEXT: [Retrieved chunks appear here] USER: Can I return an unused item after 20 days?

Retrieved content is usually supplied as context. It is not necessarily inserted into the system prompt.
